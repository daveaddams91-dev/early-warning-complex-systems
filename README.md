# Early Warning Complex Systems

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![CI](https://github.com/rajveersinh-is-dev/early-warning-complex-systems/actions/workflows/ci.yml/badge.svg)](https://github.com/rajveersinh-is-dev/early-warning-complex-systems/actions)


Mathematical research framework testing whether statistical, physical, and information-theoretic indicators can anticipate critical transitions and collapse in complex systems.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/early-warning-complex-systems.git
cd early-warning-complex-systems
python "experiments/scripts/ablate_amoc_failure.py" --help
```

## Testing

```bash
pytest tests/
```
